# 会话滚动手势设计

宽屏手势启用后，按住右键向上拖跳到当前会话已载入内容的顶部，向下拖回到消息底部。使用现有的右键轨迹、有效距离和 DSH 菜单优先规则。无前台会话时可以显示轨迹，松手后保持页面状态。

手机在当前会话中双指同向上滑到顶、同向下滑到底。两个触点都要达到纵向距离阈值，松开时只执行一次。双指间距明显改变时由浏览器处理捏合缩放；单指上下滑继续滚动，已有单指左右滑仍控制侧栏。

顶部手势只移动视口。DSH 在接近顶部时会自动请求更早消息，插件会经当前会话的原生 Chat 插槽拦住这次跳转引发的自动请求及预备页的自动插入。「加载更早」继续调用原有的手动加载逻辑。离开历史分页区或切换会话后恢复原来的分页行为。底部手势沿用 DSH 原生回到底部与跟随新消息的行为。

设置页增加到顶、到底两个独立开关，默认开启，继承浏览器本地的手势偏好。沿用 DSH 通用设置的原生开关行和插件详情容器，由宿主渲染文字、分隔线和右侧开关。

验收须包含至少还有一页历史的会话。上划后首条已载入消息不变且未自动请求更早页，随后点击「加载更早」可以正常取回。下划到达尾部后继续跟随新消息。验证双指同向、捏合、单指滚动、左右侧栏、宽屏轨迹、原生菜单及设置持久化。
