# DSH Gestures 设计

DSH Gestures（`dsh-gestures`）是 DeepSeek Harness 的 Web 插件，为原生左侧导航栏和右侧工具栏提供横向手势。首版以本机 DSH 0.2.3-alpha.2 为验证基准。

## 手势与设置

在「插件 → dsh-gestures」详情页提供以下开关。修改立即应用，保存在当前浏览器的站点设置中，刷新后继续有效。

| 设置 | 默认 | 操作 |
| --- | --- | --- |
| 展开左侧导航栏 | 开 | 从屏幕左边缘稍内侧向右滑 |
| 收起左侧导航栏 | 开 | 从左栏可用区域或窄屏遮罩向左滑 |
| 展开右侧工具栏 | 开 | 从屏幕右边缘稍内侧向左滑 |
| 收起右侧工具栏 | 开 | 从右栏可用区域向右滑 |
| 在宽屏启用 | 关 | 允许已启用的手势在宽屏使用 |

跟随 DSH 的原生抽屉布局判断窄屏。窄屏接受单指触屏滑动。宽屏开关打开后，接受相同的触屏滑动，也允许在相应区域按住鼠标右键横向拖动。普通左键操作和触控板滚动保持原有行为。

## 宽屏右键手势

- DSH 菜单优先。在会话条目、文件、标签等位置，如果 DSH 或页面组件处理了这次右键菜单事件，就取消这次手势。已经打开或正在准备的 DSH 菜单也优先响应右键。
- 右键从可触发对应手势的区域起步。松手时横向位移至少 64 CSS 像素且至少是纵向位移的 1.5 倍，就执行对应操作。快速拖动也有效，原地长按或轻微移动不会切换侧栏。
- 浏览器可能在右键按下时尝试打开原生菜单。事件先交给页面处理，手势仅在符合起点和面板状态条件、且页面未处理右键菜单的区域拦截浏览器原生菜单。在按下时弹菜单的浏览器上，从这些区域单击右键也可能不显示浏览器原生菜单。其他位置的原生菜单照常可用。

## 触发规则

- 根据起点、方向和面板展开状态决定操作。达到横向滑动阈值并松手时执行，一次手势最多改变一个面板。重复执行展开或收起的方向时保持当前状态。
- 窄屏已有侧栏覆盖页面时，只识别收起当前侧栏的手势。宽屏遵循原生分栏布局。右侧工具栏只在有可操作的前台会话时响应，收起后保留已打开的工具标签。
- 在编辑器、输入框、横向滚动区域、拖动控件和浮窗中保留原生交互。遇到纵向滚动、缩放、多指输入、系统取消、侧栏状态变化或其他模态弹层时取消候选手势。
- 打开手势避开屏幕最外侧。系统或浏览器接管的边缘手势以其原生行为为准。

## 接入与验证

通过 DSH 原生插件配置插槽渲染开关。左侧调用 `ctx.layout.toggleSidebar()`，读取框架现有的抽屉和折叠状态标记。右侧通过 `ctx.sidebarRight` 读取展开状态并调用 `toggleExpanded()`。复用原生面板动画、焦点与状态。禁用插件时移除输入监听和配置页。

用隔离的 DSH Web 实例验证插件加载、四条手势、重复滑动、设置刷新持久化及宽屏开关。覆盖右键菜单优先、快速拖动、原地长按、距离阈值、滚动、横向拖动、多指取消、输入区、无前台会话及插件禁用。验证浏览器在按下或松开时分发右键菜单事件的两种顺序。用浏览器触屏模拟验证页面集成，系统级返回手势的兼容性以实机为准。
