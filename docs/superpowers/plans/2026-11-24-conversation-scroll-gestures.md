# 会话滚动手势实现计划

- 在 `src/swipe.js` 为鼠标增加纵向判定，并用双指同向距离和间距变化识别手机定位。扩展 `test/swipe.test.js` 验证方向、距离和捏合。
- 在 `src/input.js` 复用手势生命周期、鼠标轨迹与菜单仲裁。会话动作只发给当前可见的 Chat 滚动区域。
- 通过 `conversation.view` 接入原生 Chat 的历史分页。用真实多页会话验证顶部定位、手动载入和底部跟随。
- 设置页复用宿主原生设置行，保留浏览器本地偏好和即时保存。验证字号布局、开关、窄屏滚动和热卸载。
