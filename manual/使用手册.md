# DSH Gestures 使用手册

DSH Gestures 为 DeepSeek Harness Web 的左右侧栏添加横向手势。首版针对 DSH 0.2.3-alpha.2 验证。

## 安装

通过「插件 → 添加插件」安装 `dsh-gestures-0.1.0.tgz`，或在 DSH 主机上执行 `dsh plugin --profile web add /绝对路径/dsh-gestures-0.1.0.tgz`。

## 使用

| 操作 | 手势 |
| --- | --- |
| 展开左侧导航 | 从屏幕左边缘稍内侧向右滑 |
| 收起左侧导航 | 从左栏或窄屏遮罩内向左滑 |
| 展开右侧工具栏 | 从屏幕右边缘稍内侧向左滑 |
| 收起右侧工具栏 | 从右栏内向右滑 |

在「插件 → dsh-gestures」详情页可以单独开关四种手势，并选择是否在宽屏启用。手势默认只在窄屏启用。设置保存于当前浏览器的站点存储，修改后立即生效。

宽屏开启后，可以用触屏滑动，也可以按住鼠标右键横向拖动。右键累计按住至少 150 毫秒、横向拖动至少 64 CSS 像素后松手。DSH 自己的右键菜单优先。若浏览器在按下右键时弹出原生菜单，能够开始手势的区域可能会拦截该菜单。

右侧工具栏需要有前台会话。输入区、编辑器和允许横向滚动的区域继续按原样操作。系统边缘返回手势由设备控制，可以从离边缘约 24–64 CSS 像素处开始展开手势。
