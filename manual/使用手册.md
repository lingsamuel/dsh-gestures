# DSH Gestures 使用手册

DSH Gestures 为 DeepSeek Harness Web 的左右侧栏添加横向手势。首版针对 DSH 0.2.3-alpha.2 验证。

## 安装

通过「插件 → 添加插件」安装 `dsh-gestures-0.1.3.tgz`，或在 DSH 主机上执行 `dsh plugin --profile web add /绝对路径/dsh-gestures-0.1.3.tgz`。

## 使用

| 操作 | 手势 |
| --- | --- |
| 展开左侧导航 | 从左侧或正文可用区域向右滑 |
| 收起左侧导航 | 从左栏、窄屏遮罩或宽屏正文可用区域向左滑 |
| 展开右侧工具栏 | 从右侧或正文可用区域向左滑 |
| 收起右侧工具栏 | 从右栏或宽屏正文可用区域向右滑 |

在「插件 → dsh-gestures」详情页可以单独开关四种手势，并选择是否在宽屏启用。手势默认只在窄屏启用。设置保存于当前浏览器的站点存储，修改后立即生效。

宽屏开启后，可以用触屏滑动，也可以在正文、顶栏或两侧栏的可用区域按住右键横拖。拖动时显示轨迹，横向拖足 64 CSS 像素即可松手。DSH 自己的右键菜单优先。若浏览器在按下右键时弹出原生菜单，能够开始手势的区域可能会拦截该菜单。

右侧工具栏需要有前台会话。宽屏正文里如果同一方向既可以展开一栏，也可以收起另一栏，手势操作靠近起点的一侧。输入区、编辑器和横向滚动区保留原生交互。手机从正文内起滑即可避开系统边缘返回手势。
