# DSH Gestures 使用手册

DSH Gestures 为 DeepSeek Harness Web 提供左右侧栏和会话滚动手势。针对 DSH 0.2.3-alpha.2 验证。

## 安装

通过「插件 → 添加插件」安装 `dsh-gestures-0.2.0.tgz`，或在 DSH 主机上执行 `dsh plugin --profile web add /绝对路径/dsh-gestures-0.2.0.tgz`。

在已有会话页面上启用或更新插件后，刷新页面以接入该会话的历史分页。

## 使用

| 操作 | 手势 |
| --- | --- |
| 展开左侧导航 | 从左侧或正文可用区域向右滑 |
| 收起左侧导航 | 从左栏、窄屏遮罩或宽屏正文可用区域向左滑 |
| 展开右侧工具栏 | 从右侧或正文可用区域向左滑 |
| 收起右侧工具栏 | 从右栏或宽屏正文可用区域向右滑 |

在「插件 → dsh-gestures」详情页可以单独开关六种手势，并选择是否在宽屏启用。设置保存于当前浏览器的站点存储，修改后立即生效。

宽屏开启后，可以用触屏滑动，也可以在正文、顶栏、两侧栏及栏间宽度拖柄的可用区域按住右键横拖。拖动时显示轨迹，横向拖足 64 CSS 像素即可松手。DSH 自己的右键菜单优先。同一次拖动松手后出现的浏览器菜单事件会被拦截。在按下时弹菜单的浏览器上，能够开始手势的区域也可能拦截单击右键的原生菜单。

当前方向没有可执行动作时，右键拖动照常画出轨迹，松手后侧栏保持原状。

右侧工具栏需要有前台会话。宽屏正文里如果同一方向既可以展开一栏，也可以收起另一栏，手势操作靠近起点的一侧。输入区、编辑器和横向滚动区保留原生交互。手机从正文内起滑即可避开系统边缘返回手势。

## 会话定位

- 宽屏开启手势后，按住右键上拖到顶、下拖到底。手机在会话正文双指同向上滑或下滑。
- 到顶停在已载入内容的起点。需要更早的消息时，点击 DSH 的「加载更早」。到底后由 DSH 继续跟随新消息。
- 手机单指上下滑照常滚动，捏合由浏览器处理。
